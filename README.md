# Unity-Proyecto-Ghost
Proyecto FPS top-down 3D, desarrollado en unity, con las siguientes características.  
CARACTERISTICAS  
*Sistema de disparo. 
*Sistema para usar items [Pick Up] 
*Sistema de AI. 
*Sistemas de daño. 
*Sistema de salud. 
*Particulas 
*Sistema de explosiones. 
*Sistema de movimiento (Player, AI) 
*Sistema de animaciones 
*Sistema de cámara

Technologies
Unity
C#

Project Status
In development
